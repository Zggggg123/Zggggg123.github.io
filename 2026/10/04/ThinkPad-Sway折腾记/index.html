从虚拟机到 ThinkPad：我的 Linux 折腾记录

2026-10-04 更新于 2026-10-04
  • 折腾记录
  • Linux
  • Sway
  • ThinkPad
  • Ubuntu

最近买了台 ThinkPad 做副机，打算拿来看网课、写作业，顺便学 Linux。装系统倒没花太久，后面配平铺窗口管理器花了两天。

把之前的虚拟机练习也算上，记一下这次从装系统到折腾桌面的过程。

注：本文基本由ai总结，我只做小部分修改

一、虚拟机练习

买笔记本之前，我先在 VMware 里装了 Arch+i3wm

装好 GNOME，选了中文，结果字体没装全，界面上都是方框。为了方便操作，我开了 SSH，从 Windows 连进去补字体，又检查了驱动和 VMware Tools。后来还装了 Fastfetch为了装逼

接着试了 fish。了解了pacman -S 和 -Syu 的区别、用chsh把fish设置成默认shell 。

第一次玩平铺窗口管理器用的是 i3。装完找不到登录选项，查了半天，发现最初的安装命令漏了 Xorg。补上之后，终于进了那个黑乎乎桌面，选 Win 键作修饰键，按 Win + Enter 开终端，几个窗口就自动排好了。

不过中文又来添乱：xterm 先是方框，换字体以后能显示了，字间距却大得离谱。来回试了几次，还是宽，又讨论了换终端。那个时候觉得不算大事，后面才发现这个中文输入到底有多难。

这段主要是在虚拟机里练手。后来笔记本上的 Ubuntu 和 Sway，是另外一次安装。

二、选笔记本

咸鱼上蹲了好多天，最后实际买回来的是 X1 Carbon G8，i5、16GB 内存、256GB SSD、14 寸 2K 屏，买它主要是因为看上它只有1Kg，可以背着到处跑。

用途没什么复杂的：看网课、编辑文本、写学校作业。留了一个 Windows，以后有些软件需要用，Linux 则拿来日常学习和折腾。

发行版一开始没完全定下来。Arch 在虚拟机里玩过，CachyOS 也考虑过，但后来想想，我不太喜欢滚动更新，还是 Debian 系、固定版本的系统更适合这台副机。最后选了比较熟悉的 Ubuntu。

最后Win和Linux各拿120g。

三、第一次 Linux 配置：折腾到想重装

第一轮是在 Ubuntu 24.04 上配 Sway。我想用键盘切窗口，也喜欢平铺桌面，看起来很适合一边看课一边记东西。

结果花时间最多的地方是中文输入法。

GNOME Terminal 里有时正常，Firefox 的候选框却不跟光标；换到 Foot、Kitty，又可能连候选框都没有。2K 屏开了缩放以后，位置问题更明显。试过改环境变量、注销、重启，再换一种启动方式，结果总是不一样。

中间还有一次，我忘了关原来的 Firefox 进程，以为是在测新的设置。关干净重开，才发现刚才的测试不算数。fish 的命令写法、Firefox 的 Snap 路径，也都绊过一下。

折腾到后来，我直接问：“Sway 好难啊，能不能全删了换 Hyprland？”也想过卸载干净，再重装 Sway。还没决定好，回到 Ubuntu 默认桌面，连那边的输入法也不正常了。

最麻烦的是，我已经记不清之前改了哪些东西。

于是决定保留 Windows，把 Ubuntu 重装。中途考虑过 EndeavourOS + i3，但最后还是选了 Ubuntu 26.04，熟悉一点，少换一套东西。

四、第二次 Linux 配置：终于能用，再慢慢改

第二天，我还是想用 Sway。又聊了 Debian 和 Ubuntu 的选择，最后没再换系统，就在新装的 Ubuntu 上继续。

这次我让 Codex 通过 SSH 连到笔记本，直接检查和改配置，我在屏幕前确认效果。实机上是 Ubuntu 26.04.1、Sway 1.11，屏幕先设成 150% 缩放。之前关于 Sway 输入法的回答也有过时的地方，核对版本后重新配置，浏览器和终端终于都能输入中文，候选框也跟着光标走了。Foot 的中文间距再单独调了一次，才算正常。

这次先把能用的配置备份下来，再开始美化。我想要深色、简单一点的桌面，最初用了蓝灰配色，后来找了 gnuunixchad 的 dotfiles 作参考，改成黑灰底色、绿色边框，窗口之间不留空隙。

终端换成 Kitty，启动器用 Wofi。Kitty 一开始打开要等一秒多，后来加了后台预启动，快了不少。查看进程时那个关闭确认也关掉了。

顶部栏也改了好几轮。左边放工作区和当前终端路径，中间只显示时间，悬停看月历；右边放托盘、通知、网络、蓝牙、音量、亮度和电池。14 寸屏幕空间紧，尽量用图标，CPU、内存数字后来也删了。

几个小功能反而来回改得最多。点击路径原来是选目录开终端，后来改成用 Nautilus 打开当前目录。我试过换成 nnn，很快又撤销了：终端里敲 nnn 本来就方便，既然已经用鼠标点路径，还是图形文件管理器顺手。

Wi-Fi 换成直接选附近网络。月历看起来“一行八天”，后来发现多出来的是周数，真正的问题是字体没对齐。

亮度最初只能改数字，屏幕没反应，修了背光权限后才真能调。又改了滚轮方向和数字刷新，最后我干脆取消亮度滚轮，留下栏下的小滑块，把“保持亮屏”也放进去。电池则做成性能模式和电源菜单。

期间还遇到过锁屏变红、注销后 Waybar 不启动。红屏当次恢复了，Waybar 调整了启动顺序，这两个还要在之后使用中继续看看。又修了太阳图标的样式问题：开启保持亮屏时，图标会放大、重复铺满背景，现在恢复成单个小太阳了。

最后换壁纸，我只写了图片路径，忘了后面的 fill，又报了一次错。改好以后，也问清楚了以后自己换图该改哪个文件。

这是修复亮度图标后新截的实机图，两个终端里的文字是临时准备的展示内容。

现在这台副机总算有点能用了。看课、记东西、开文件，都有顺手的入口。后面肯定还会改，但先用一阵子吧，毕竟买回来是为了学习，不能一直拿它配桌面。

五、窗口管理器下的常用快捷键

顺便把这套 Sway 的快捷键记在这里，免得过几天又忘了。下面按我现在的配置写，Win 就是键盘上的 Windows 标志键。

快捷键 功能
Win + Enter 打开 Kitty 终端
Win + D 打开 Wofi，输入名字搜索应用
Win + Shift + B 打开浏览器
Win + Shift + T 打开文本编辑器
Win + Shift + N 打开文件管理器
Win + 方向键 切换到对应方向的窗口
Win + Shift + 方向键 移动当前窗口
Win + 数字 切换工作区，0 对应第 10 个
Win + Shift + 数字 把当前窗口放到对应工作区
Win + B / Win + V 让后面新开的窗口左右 / 上下排列
Win + F 全屏，再按一次退出
Win + Shift + 空格 在平铺和悬浮之间切换
Win + R 进入调整大小模式，用方向键调整，Enter 或 Esc 退出
Win + Shift + Q 关闭当前窗口
Win + Esc 锁屏
Win + Shift + E 弹出注销确认
Print / Win + Shift + S 全屏截图 / 框选截图
Win + Shift + C 重新加载 Sway 配置

窗口多了可以分到不同工作区，比如 1 放网课，2 写作业，3 放参考资料。切换窗口用 Win + 方向键；加上 Shift 就变成移动窗口，刚开始很容易按混。

不想让某个窗口参与平铺，就按 Win + Shift + 空格让它悬浮。想把网课或文档暂时铺满屏幕，用 Win + F 就行。

这些键也都能自己改，配置在 ~/.config/sway/config。保存后按 Win + Shift + C 重新加载。音量和亮度继续用键盘上的功能键，部分 ThinkPad 设置下要配合 Fn。
